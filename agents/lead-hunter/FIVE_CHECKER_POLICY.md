# Five-Checker Policy

## Cold outreach — all five required

### Checker 1 — FIT
PASS only if:
- prospect matches active offer ICP;
- decision-maker role is relevant;
- company is not already in an active duplicate sequence;
- there is a concrete reason this offer could matter to this business.

### Checker 2 — CONTACT EVIDENCE
PASS only if:
- person/company identity is verified;
- address/channel is sourced, not guessed;
- provenance is recorded;
- contact is not suppressed or unsubscribed.

### Checker 3 — MESSAGE QUALITY
PASS only if:
- message is specific to the prospect;
- factual personalization is supported by evidence;
- CTA is simple;
- pricing and deliverables match the current offer;
- no unsupported promises, invented customers, or fabricated urgency.

### Checker 4 — COMPLIANCE
PASS only if:
- consent/legal basis is recorded;
- commercial message is relevant to recipient role;
- sender identity and valid contact method are included;
- unsubscribe mechanism is included;
- jurisdictional suppression rules pass.

### Checker 5 — TRUTH / REPUTATION
PASS only if:
- every material statement is supportable;
- tone is respectful and not deceptive;
- no false scarcity, fake social proof, hidden terms, or misleading subject line;
- sending the message is reasonable for RC Emporium's reputation.

## Decision rule

- 5 PASS = SEND ELIGIBLE.
- Any FAIL = BLOCK.
- Any UNKNOWN = BLOCK until resolved.
- Reviewers must produce independent verdicts before seeing other reviewer verdicts.
- Final arbiter may only approve when all required reviewers passed; it may never override a failed compliance or evidence checker.

## Routine replies

Three independent reviewers are mandatory:
1. Context/intent checker.
2. Truth/message-quality checker.
3. Compliance/reputation checker.

Any medium/high-risk content automatically invokes all five checkers.

## Failure handling

- Maximum 2 automated redraft cycles.
- If still failing: queue for founder review.
- Never keep retrying indefinitely.
- Never send a partially approved draft.
